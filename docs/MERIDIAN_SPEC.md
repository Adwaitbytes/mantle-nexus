# MERIDIAN - Institutional RWA Yield Protocol

## Product Vision
MERIDIAN is a category-defining, institutional-grade protocol for tokenizing, trading, and optimizing yield on real-world assets (RWAs) built natively on Mantle Network.

## Why MERIDIAN Wins

### Track Coverage
- **Primary:** RWA/RealFi ($15K) - Core product focus
- **Secondary:** DeFi & Composability ($15K) - Yield aggregation engine
- **Tertiary:** AI & Oracles ($15K) - Risk assessment AI
- **Bonus:** ZK & Privacy ($15K) - Compliance layer
- **Grand Prize:** ($30K) - Category-defining innovation

### Unique Value Proposition
1. **First institutional-grade RWA protocol on Mantle** - Not a toy, not an MVP
2. **Real-time yield optimization** - Composable strategies across asset classes
3. **Regulatory-ready architecture** - ZK-KYC with selective disclosure
4. **AI-powered risk scoring** - Real-time portfolio health monitoring
5. **Deep Mantle integration** - Leverages low fees for micro-transactions

## Design System

### Color Palette
- **Background:** Deep slate (#0A0E14) transitioning to navy
- **Primary:** Gold/Amber (#F59E0B) - Represents yield/value
- **Accent:** Emerald (#10B981) - Positive indicators
- **Destructive:** Rose (#F43F5E) - Risk warnings
- **Muted:** Slate grays for supporting text

### Typography
- **Display:** Geist (clean, modern, institutional)
- **Body:** System fonts for performance

### Motion Design
- Particle systems for asset flow visualization
- Number tickers for real-time metrics
- Staggered reveals for dashboard elements
- Smooth state transitions (no jarring changes)
